# Photos produit

Déposez ici les photos du catalogue. **Le nom du fichier doit correspondre au
slug du produit** ; l'image est alors détectée automatiquement au prochain
`npm run dev` / `npm run build`. Sans fichier, la fiche affiche un visuel
neutre — jamais une image cassée.

| Produit             | Fichier attendu                        |
| ------------------- | -------------------------------------- |
| Amoxi-Denk 500      | `amoxi-denk-500.jpg`                   |
| Amoxi-Denk 1000     | `amoxi-denk-1000.jpg`                  |
| Nexium 40 mg        | `nexium-40.jpg`                        |
| Rabetok D           | `rabetok-d.jpg`                        |
| Amaday 5 mg         | `amaday-5.jpg`                         |
| Ibumol (sirop)      | `ibumol-sirop.jpg`                     |
| Nuravit (sirop)     | `nuravit-sirop.jpg`                    |
| Litacol (sirop)     | `litacol-sirop.jpg`                    |

Extensions acceptées : `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Conseils de prise de vue : cadrage carré, boîte entière et bien lisible, fond
clair et uni. Les cartes utilisent `object-contain`, donc l'emballage n'est ni
recadré ni déformé, et le texte imprimé reste intact.
